# SeiNu Labs (செயற்கை நுண்ணறிவு)

> **SeiNu** is derived from *Seiyarkai Nunarivu* (செயற்கை நுண்ணறிவு) — Tamil for **Artificial Intelligence**.

**SeiNu Labs** is an applied AI engineering space focused on local runtime infrastructure—currently centered on local environments, with plans to scale upward—model orchestration, and developer tooling.

---

## 🚀 Featured Project

### **Ollama Studio & Mission Control**

A management dashboard and testing suite built from the ground up as a **developer-first tool** for multi-instance Ollama environments.

#### Key Features

* **Multi-Instance Management:** Discover, connect, and monitor multiple Ollama hosts and instances from a single workspace.
* **Model Arena:** Side-by-side prompt testing, response evaluation, and comparison across different models and instances.
* **Developer-First Design:**
  * **Direct JSON Import:** Import raw JSON request payloads directly into the runner to replay and tweak requests with zero friction.
* **Broad Task & Model Support:**
  * **Text Generation:** Run and benchmark autoregressive models like `llama`, `gemma`, and others.
  * **Embeddings & Similarity Search:** Test vector generation and similarity workflows with models like `embeddinggemma`.
  * **System 1 Models:** Decision models such as `tev` and `laya`.
* **Model Lifecycle Operations:** Pull, delete, inspect, and manage models across connected Ollama instances.
